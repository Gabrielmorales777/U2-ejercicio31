# U2-ejercicio31
# Sistema de Lectores de Documentos Digitales

**Objetivo principal:** desarrollar un sistema modular de lectura de documentos en Java utilizando clases abstractas, herencia y polimorfismo para gestionar diferentes formatos de archivos.

El ejercicio implementa una clase abstracta `LectorDocumento` y tres clases concretas: `LectorPDF`, `LectorWord` y `LectorTextoPlano`, cada una con su propia lógica de apertura y extracción de texto. Además, incorpora validaciones para comprobar que los archivos tengan extensiones compatibles y utiliza listas para procesar distintos documentos de manera modular.

**Conceptos aplicados:** clases abstractas, herencia, polimorfismo, encapsulamiento, sobrescritura de métodos, ArrayList y validaciones.
